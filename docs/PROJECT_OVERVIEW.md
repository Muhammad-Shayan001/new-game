# AFTERLIFE.EXE — Project Overview
- Engine: Godot 4.x (GDScript, Mobile renderer) | Platform: Android first, Windows PC later
- Tools: Blender, Krita/GIMP, Audacity, Git (free/open-source only)
- Type: single-player offline campaign + optional 1–4 player co-op (never required)
- Camera: third-person | Look: cinematic, atmospheric, optimized 3D
- Premise: Alex Morgan wakes in Echo City with no memory. Message: "YOU WERE NEVER SUPPOSED TO REMEMBER."
- Themes: memory, identity, loss, truth, choice, meaning of existence
