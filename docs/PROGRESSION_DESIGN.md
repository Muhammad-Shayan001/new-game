# Progression Design
Progression is **discovery-based**, never grind-based.

| Layer | What changes | Source |
|---|---|---|
| Abilities | New traversal/puzzle verbs | Story missions (Memory Sight Ch1, Reality Shift + Time Echo Ch3, Echo Voice Ch5) |
| Memory completion | Journal pages, new dialogue prompts, Deep Fragments | Fragments (30) |
| Deductions | Door codes, dialogue options, shortcuts | Linking clues |
| World access | Districts open as story advances | Mission completion |
| Relationships | Ending eligibility, optional scenes | Decisions and optional dialogue |

## Pacing
Ch1 tutorial, Ch2 first Memory puzzles, Ch3 ability spike, Ch4 mixed use, Ch5 decision-heavy, Ch6 mastery finale using all abilities.

## Rules
- No level scaling, no currency, no repeated farming.
- Every optional item must reveal story, a clue, or an ending flag.
- Missed collectibles are recoverable via Chapter Replay.
- Ability upgrades only happen once and are story-tied.
