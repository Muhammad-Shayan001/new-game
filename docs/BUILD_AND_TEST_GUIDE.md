# Build and Test Guide
1. Install Godot 4.3+ and open `project.godot`.
2. Android export: install JDK 17, Android SDK, set paths in Editor Settings, add an Android export preset, enable USB debugging, deploy.
3. Test checklist: launches, save/load round-trip, movement on device, no crashes in 10 min session.
